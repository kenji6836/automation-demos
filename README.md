# automation-demos

業務自動化のデモ集（受託サービスのサンプル）。各フォルダに README・コード・動作 GIF があります。

| デモ | 内容 | 対応サービス |
|---|---|---|
| [gas-sales-report](gas-sales-report/) | 売上 CSV → Google スプレッドシート月次集計 → メール/Slack 通知（GAS） | GAS / スプレッドシート業務効率化 |
| [estat-to-sheet](estat-to-sheet/) | e-Stat 公式 API → スプレッドシート自動更新 | Web データ収集ツール制作 |
| [inquiry-reply-assistant](inquiry-reply-assistant/) | 問い合わせメール → 要約＋返信下書き（Claude API） | AI 自動化ツール制作 |

開発は Claude Code（AI）を活用し、設計・検証・納品は人が行います。
